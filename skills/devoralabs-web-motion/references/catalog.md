# Motion catalog — 240 entries

220 visual effects/patterns + 10 input triggers + 10 timing modes. IDs follow the original requested list. Variants can overlap; these are not 240 mutually exclusive industry standards.

Each GIF is a deterministic Canvas study, not a recording of a production website. The interactive input, shader and 3D limits are labeled per group. A looping GIF shows repetition for teaching; production replay follows the user task and reduced-motion preference.

[Open the searchable gallery](../assets/catalog/gallery.html) through a local HTTP server. On GitHub, open a group below to view its ten GIFs.
